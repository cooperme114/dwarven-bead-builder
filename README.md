# Dwarven Guest Bead Builder

A small browser-based worksheet for building the foreign-guest necklaces used in the Dwarven kingdom of the Haven campaign.

## Run locally
Open `index.html` in a browser.

## GitHub Pages
In the repository, go to **Settings → Pages**, choose **Deploy from a branch**, select **main** and **/(root)**, then save.

The app currently includes:
- 10 personal-information bead categories
- 7 toggleable Dwarven House-support beads
- multiple spouse/child/crime/crisis beads where appropriate
- an Adessa preset
- a live necklace preview
